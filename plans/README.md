# Motion & Animation Improvement Roadmap

This directory contains prioritized, self-contained implementation plans generated by the `improve-animations` senior motion advisor. Each plan targets a specific finding audited against Emil Kowalski's animation philosophy (`animations.dev`), WCAG accessibility standards, and 60fps GPU compositor hygiene.

---

| Plan | Title | Severity | Category | Status |
| :--- | :--- | :--- | :--- | :--- |

## Recommended Execution Order

```
[Phase 1: Foundation]
  └── 006 (Centralize motion tokens in src/styles/motion.ts)

[Phase 2: High-Severity Bug & Accessibility Fixes]
  ├── 001 (Eliminate transition-all transform conflicts on metric & contact cards)
  ├── 002 (Implement prefers-reduced-motion across CSS, Hero tilt, and Lenis)
  └── 003 (Ground icon scale from 0.40 up to 0.88-0.90)

[Phase 3: Interaction & Timing Optimization]
  ├── 004 (Accordion asymmetric timing: 220ms open / 130ms collapse)
  └── 005 (Remove accidental tab thrashing on hover in Services)

[Phase 4: Editorial Polish & Choreography]
  ├── 007 (Mobile drawer cascade stagger & tool pill stagger)
  └── 008 (Blur-masked text crossfade on service tab transitions)
```
